# 问否 0.3 · 外部问答导入

## 使用流程

1. 在 DeepSeek、ChatGPT、豆包或 Kimi 中复制公开分享链接，或复制问答文字。
2. 返回问否，前台获得窗口焦点后检查文字剪贴板；同一内容不重复提醒。也可以点顶部「导入」，或通过 Android 系统「分享 → 问否」进入。
3. 确认解析。文字在本机解析；链接使用本机 WebView 加载来源平台的公开网页。
4. 核对问题、回答、来源；多轮对话选择一轮。仅复制了答案时必须补充问题。
5. 确认进入发布预览。已有草稿须明确确认替换。分享文字会附来源平台及原分享链接。

**当前社区后端尚未连接，确认后是本地发布预览和系统文字分享，不会产生社区帖子。**

## 本版范围

- 公开分享地址：DeepSeek `/share/`、ChatGPT `/share/`、豆包 `/thread/`、`/s/`、`/share/` 和 `v.doubao.com` 短链接、Kimi 新旧域名 `/share/`。
- 支持中文「问题/提问/问/用户」「回答/答案/答/助手/豆包」等行首标签，以及英文 `You said` / `ChatGPT said` 等标签。
- 无标签文字保留为答案，要求补充问题；代码围栏中的问答标签保持原样。未标注的前言保留为独立片段，可在轮次选择中查看。
- 图片、视频、附件、语音、跨页面分页及完整 Markdown 样式不在本版范围。导入网页中已加载的文字，长对话需用户核对。
- 最多读取 12 万字符、100 条网页消息；确认问题上限 1 万字符，回答上限 10 万字符，超限提示处理，不静默截断导入答案。
- 「导入」页可关闭自动识别。应用只保留最近 32 个内容摘要用于去重，不保存剪贴板原文历史；草稿仍是当前会话状态。

## 实现

- `ShareImport.kt`：公开地址白名单、链接识别、文本角色与轮次划分、SHA-256 去重。
- `share-extractor.js`：平台 DOM 适配，读取渲染的消息节点，不调用平台私有接口。
- `ImportDialog.kt`：粘贴、加载、错误降级、编辑核对、轮次选择。
- `MainActivity.kt`：前台剪贴板、系统分享 Intent、草稿保护、预览及来源标识。

WebView 仅允许对应平台的公开分享路由作为顶层导航；HTTPS、禁用文件访问及混合内容，不注入原生 JavaScript bridge。登录、验证、失效链接、页面结构变化均可退回文字导入。平台来源来自 URL 或用户选择；标签不代表问否验证了模型身份或回答准确性。

## 真机验收

- 在来源 App 复制链接 → 切回问否 → 确认解析 → 核对 → 进入预览。
- 豆包只复制回答 → 自动提示 → 手动补充问题 → 预览。
- 取消提示后多次切换 App，同一内容不再次打扰。
- 修改剪贴板内容后再次提示；关闭开关后停止自动识别。
- 无网络、已撤销链接、登录/验证墙：显示失败原因并可以改用文字。
- 导入新内容时取消替换，原草稿保留。
