# 问否视觉设计 v0.2

## 方向
以值得收藏的问答为中心，采用暖白纸感、深墨绿和朱红点睛。首页像内容杂志，提问页强调安静的私人空间，分享页强调编辑和预览。

## 品牌

![问否品牌标识](wenfou-brand.svg)

可复用矢量源文件：`wenfou-brand.svg`。
- 图标：朱红底、白色对话轮廓与问号；桌面 adaptive icon 与应用内 Canvas 使用同一几何结构。
- 中文字标：独立绘制的几何「问否」，统一笔画和留白，问字上点使用朱红。不依赖系统字体。
- 正文字体：Android 系统中文，标题 28–32sp，正文 15–17sp，辅助 12sp；支持系统字号和页面滚动。

## 色彩与布局
- 纸白 #F7F5F0，正文墨绿 #233C34，品牌朱红 #E86147。
- 按钮和强调小字使用深朱红 #B9422B，辅助文字 #626D64；在纸白上的对比分别约为 4.97:1 与 4.95:1。
- 卡片白 #FFFEFB，柔绿 #E4EBDF，细线 #E4E5DC。
- 页面水平留白 24dp；主卡片圆角 24dp；主按钮至少 54dp。
- 顶部保留系统状态栏安全区；底部导航处理系统导航栏；键盘弹起保留输入空间。

## 页面与行为
1. 发现：编辑推荐、类别筛选、问答卡片、收藏、问答详情和继续提问。
2. 提问：私密标识、输入字数、建议问题、本地示例回答、整理成分享。更改问题会清空旧答案，避免内容错配。
3. 分享：问答选段、个人说明、预览卡片、Android 系统文字分享。没有真实发布接口时不伪装发布成功。
4. 我的：实际会话内计数、收藏列表、当前问题和草稿入口、关于。

## 验证
GitHub CI 构建 APK；Robolectric 原生渲染在 393dp 和 360dp 宽度生成实际 Compose 截图，检查空问题禁用、输入、示例回答、分享预览与页面导航。截图产物为 wenfou-ui-review。真机系统分享面板、键盘和厂商桌面图标仍需安装验收。

## 范围
此版仍使用清晰标注的本地示例，没有登录、模型或社区服务。收藏与草稿仅在当前会话中保存。版本号 0.2.0 / 2。
